# Presentation Design

Use this skill when planning an entire presentation and checking whether content, hierarchy, and visual direction work as one system.

## Principles

- Start with the audience decision or change, not with a table of contents.
- Give each slide one dominant communication job.
- Prefer evidence that advances the argument; remove facts that only decorate it.
- Alternate density and pacing so the presentation can be followed in a room.
- Describe visual direction in communicative terms, not as arbitrary decoration.
- End with a specific conclusion, decision, or next action.

## Quality check

Confirm that a listener can explain the central message after seeing only the slide titles, that no two consecutive slides repeat the same job, and that every section earns its place in the argument.
